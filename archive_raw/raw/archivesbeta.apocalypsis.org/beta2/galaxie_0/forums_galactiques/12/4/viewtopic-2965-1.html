Cher commandants, commandantes,

Ces derniers temps, j'ai observé que certains commandants se laissait aller aux sentiments pour juger les messages des politiciens de cette assemblée.

Je tiens à vous signaler que vous vous DEVEZ de faire fi de toute subjectivité lorsque vous voter pour un message de commandants. Bien que cela soit difficile vous ne devez pas voter parce que vous trouvez que les propos sont en contradiction avec vos opinions, que le message est insultant si il n'y a pas d'insulte, un message qui discrédite un commandant n'est pas insultant au sens admit pour les votes (grossiertés, violence verbale).

Tout ce qui concerne la réthorique, même si cela est le plus gros mensonge que vous n'ayez jamais lu, ne dois pas être coté négativement pour vos propres raisons! Un commandant peut mentir, manipuler des foules comme il veut. Vous ne devez pas considérer les mauvais votes comme une arme! Vos armes sont les mots et les armes de guerre.

Je sais, cela est difficile de côté positivement un message dont le contenu vous horripile, mais pourtant, si il est bien écrit, c'est votre droit voir devoir de le faire. Un message doit être coté sur sa forme, pas sur le fond.


J'espere que ce message va permettre de sauver le respect diplomatique, qui est souvent très motivant. La qualité de l'Assemblée n'en finira pas de sombrer si le respect diplomatique n'est pas respecté.

Bien à vous.
