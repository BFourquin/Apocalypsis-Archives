Il me semble qu'il serait judicieux d'écrire ici un "lexique" des possibilités d'écriture, pour que tout le monde face ainsi des message agréables à lire.

Alors je lance une référence pour les codes.

COULEURS : (enlever les espaces pour que le code fonctionne !)

Vert : [ green ] Texte [ / green ]

Rouge : [ red ] Texte [ / red ]

Jaune : [ yellow ] Texte [ / yellow ]

Rose : [ pink ] Texte [ / pink]

[...] etc...

Pour faire simple, mettez le nom de la couleur que vous voulez en Anglais !


PRESENTATION:

Gros et Grand: [ big ] Texte [ / big ]
Gras : [ b ] Texte [ / b ]
Petit : [ small ] Texte [ / small]
Souligné : [ u ] Texte [ / u ]



Plusieurs choses sur un mot :


Si vous voulez dire "Bonjour", en soulignant, en gras et en rose, par exemple, c'est faisable ! Donc (toujours sans les espaces):

Bonjour !

[ u ] [ b ] [ pink ] Bonjour ! [ / pink ] [ / b ] [ / u ]

Si le " [ u ] " est en premier, il doit être dernier. Si le "[ b ]" est deuxième, il doit être ensuite avant-dernier. Si le "pink" est dernier, il doit être premier !

Facile ! ;o)



Voilà, c'était principalement pour les "nouveaux"...Plus d'excuse, maintenant !

Et quand je parlais d'impossibilité, pour être plus clair, c'est pour savoir si tout ce qui est normalement possible en BBcode était possible ici (ou s'il y avait des choses que l'on ne pouvait pas faire, qui ne marchaients pas : des impossibilités, en somme) :

- pouvoir faire des listes ;
- écrire en barré ;
- écrire en caché ;
- centrer le texte ;
- le mettre à droite ;
- le faire défiler ;
- citer ;
- j'en passe et des meilleurs.

En fait, après réflexion, je pense que le mieux serait d'essayer, puis de lister les possiblités. Testons pour montrer ce qui marche :
