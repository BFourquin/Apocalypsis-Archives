- commandant Arkkrad : toutes les ressources ;
- commandant paterson : la planète.

Si les enchères sont proportionnelles :
- les ressources valent environ 278.677.900 leems (au lieu de 172.000.000) ;
- la planète vaut 50.000.000.000 (50 Ma) leems (au lieu de 6.000.000.000 (6 Ma) leems).

J'explique le prix des ressources (si les prix sont proportionnels) :

ressources = r = 172.000.000 leems
totalité = t = 6.172.000.000 leems
ressources après l'enchère d'Arkkrad = r'
totalité après l'enchère d'Arkkrad = t' = 10.000.000.000 leems

t/t' = r/r'
<=> r' = (t'*r)/t
<=> r' = (10.000.000.000*172.000.000)/6.172.000.000
<=> r' = 278.677.900

ressources après l'enchère d'Arkkrad = 278.677.900 leems
