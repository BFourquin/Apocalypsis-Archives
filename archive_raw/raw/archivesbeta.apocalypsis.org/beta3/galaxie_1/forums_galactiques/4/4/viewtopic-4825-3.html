Le chiffre magique est un chiffre qui, quelque soit par quel chiffre il est multiplié, revient à l'original

3*1 = 3
3*2 = 6 (bon ca marche déjà pas mais je continue)
3*3 = 9
3*4 = 12 12 c 1 + 2 = 3 là ca marche
...
3*10 = 30 c 3 + 0 = 3 c bon
3*100 = 300 c 3 + 0 + 0 = 0 c bon
