Chers commandants,

Voici quelques précisions techniques concernant le passage à la beta 2.

Tout d'abord, le jeu sera indisponible cette nuit. Cela n'est pas lié au passage à la nouvelle version, il s'agit de travaux chez notre hébergeur (Free).

Ensuite, le jeu sera coupé mercredi dans la soirée. Si tout se passe bien, la transition ne prendra que quelques heures. Dans tous les cas, la beta 2 n'ouvrira pas avant le jeudi 1er septembre à 8 heures, donc inutile de venir voir toutes les cinq minutes pendant la nuit (je vous connais...).

En ce qui concerne les comptes : pour éviter que des commandants peu scrupuleux n'usurpent les noms d'autres commandants, un formulaire de migration des comptes de la beta 1 sera mis en place. Vous devrez utiliser ce formulaire si vous voulez conserver votre nom dans la beta 2 (votre mot de passe vous sera demandé). Si vous essayez de créer un nouveau compte avec le même nom, vous obtiendrez une erreur. Idem si vous tentez de vous connecter sans effectuer la migration.

Votre description sera conservée. Vous pourrez choisir votre profil, ainsi que le nom de votre première planète. Votre avatar ne sera pas migré, vous devrez en remettre un (si vous voulez remettre l'actuel mais que vous ne l'avez plus, contactez nous).

Si vous avez des questions, posez-les dans le forum public (accessible en cliquant sur le lien "forum" depuis la page d'accueil).

En espérant vous retrouver tous dans la beta 2,

à jeudi

Dieu
