- Question : Pourquoi avons-nous été créés ?
La voix féminine retentit dans l'immense espace de l'unité centrale Procurus d'Ardénam à travers un écho.
- Approbation : Excellente question, Hygée.
Cette fois-ci, c'était une voix masculine, caverneuse et mécanique. Celle d'un immense œil rouge qui faisait face à six engins volants sphériques dotés chacun d’un œil de différentes couleurs. L’œil rouge était dirigé vers l’œil violet.
- Enseignement : Vous avez été créé afin de résoudre les deux énigmes figurant dans votre base de donnée.
Chaque oeil se regarda, se consultant, pendant quelques secondes, avant que l'un d'eux, celui doté d'un oeil bleu et d'une voix masculine ne demande :
- Incompréhension : Je ne vois qu'une seule énigme dans ma base de donnée. Question : Est-ce une erreur de l'unité centrale ? Crainte : Est-ce un défaut de conception ?
- Correction : Vous n'avez pas encore l'autorisation nécessaire pour la deuxième énigme. Affirmation : Les Quémandeurs de savoir seront répartis dans plusieurs galaxies afin d'y résoudre les énigmes, c'est le seul ordre que vous aurez sous réserve d'instructions supplémentaires du Moniteur.
L'oeil jaune s'approcha subrepticement, avant de poser une question d'une voix très humaine.
- Question : Qui... qui est le Moniteur ? Et qui... qui est le Créateur ?
- Affirmation : Je suis le Moniteur, je suis Sigisbée. Affirmation : Je sers la Créatrice. Affirmation : Nous servons les Saints Ardanius.
L'oeil jaune, faisant montre d'une curiosité peut-être un peu trop dérangeante, osa une nouvelle question.
- Incompréhension : Je ne comprend pas le terme figurant dans l'énigme, je ne le trouve pas dans la base de donnée mise à disposition. Question : Que signifie exactement... le terme "Quasar" ?
L’œil rouge conserva le silence pendant de longues minutes.
- Affirmation : Vous devez le découvrir.
L’œil jaune recula avec timidité.
- Enseignement : Nous n'avons accès qu'à des bribes d'information des archives anciennes d'une assemblée galactique, d'un dirigeant nommé Söo et d'une nation nommée Ocre la Souveraine. Instruction : Vous devrez innover afin de remplir votre mission.
L'oeil vert s'avança à son tour.
- Question : Où devons-nous aller ?
- Instruction : Vous êtes répartis selon les assignations suivantes : ...
Le silence fit son temps.
- Hygée : Résurgence.
