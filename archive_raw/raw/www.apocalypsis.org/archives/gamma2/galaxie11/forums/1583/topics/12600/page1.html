Et voici le moment que vous attendiez tant!
Voici la première partie du KILL GAME!
Pour ceux qui sont intéressés, voici donc les explications pour la détermination du résultat aléatoire! Le KILL n'étant pas friand de mathématique, je crois qu'il s'est déjà enfui de la salle!
A chaque vote correspond une opération. Chaque opération sera placée dans l'ordre des votes afin d'obtenir un calcul. La première opération du calcul sera la plus votée, et ainsi de suite. En cas d'égalité de vote, ce sera l'opération la plus haute sur le panneau de vote qui sera prioritaire.
Exemple :
x7 => 1 vote
+19 => 3 votes
+48 => 3 votes
x13 => 3 votes
+31 => 4 votes
x27 => 3 votes
+3 => 0 votes
Le calcul sera donc :
31 +19 +48 x13 x27 x7 +3
A noter que pour la première opération, le signe de calcul est automatiquement retiré.
Le résultat est calculé sans respect des priorités données aux multiplications (afin d'assurer un résultat le plus aléatoire possible)
Ce qui nous donnerait un résultat de : 240 789
Sur cette partie, nous avons 19 participants, le 20ème est donc à nouveau le premier. Nous déduisons donc qui serait le 240 789ème.
240789/19 = 12673,105 (permet de déterminer le nombre de tour de table complet, sans résultat)
Donc 12673x19 = 240787
240789-240787 = 2
Dans cette hypothèse ce serait donc le participant numéro 2 qui serait le Grand Perdant! A savoir, M Kaleb.
Biensur pour ceux qui n'aiment pas les maths, pas la peine de réfléchir, il vous suffira de nous faire confiance! Le calcul a simplement été exposé pour assurer une impartialité et une transparence totale sur le déroulé du jeu!
Par ailleurs, suite à la demande expresse de Monsieur Guimli, nous l'avons retiré de la liste des participants, ce dernier a choisi de payer immédiatement son tribut pour ne pas participer aux 10 prochaines parties. Si d'aventure, d'autres personnes souhaitaient effectuer une transaction similaire, nous accepterons. Nous savons être conciliants!
Autres informations :
- Durée du vote 2 jours
- Résultats masqués (pourra changer sur de prochains jeux pour vous permettre de manipuler un minimum les résultats!)
- Les coalitions peuvent aussi voter!
- Tout moyen de triche est autorisé! Seul le résultat final sera implacable!
