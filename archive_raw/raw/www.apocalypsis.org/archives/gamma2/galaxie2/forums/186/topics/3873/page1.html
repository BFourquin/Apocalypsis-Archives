Une procédure de Défiance est Lancée ...
Modalités :
La défiance est un vote à majorité simple sur 3 cycles (Ce qui est amplement suffisant), faisant apparaître trois choix :
Le défiant / Le défié / Le Blanc ...
En cas d'égalité entre le défiant et le défié, un second tour de 2 cycles est lancé sans le choix "Blanc".
Tous les Cdts peuvent voter / Les coalitions ne peuvent pas voter.
Nombre d'inscrits = 83
La conséquence :
Le défiant si il l'emporte se verra remettre la capitale d'Espoir. Il y'aura dès lors une fin propre, nette et acceptée de l'Aryakisme en Espoir.
Note :
Le cdt. Patogasse est porteur d'un projet ouvert en complément de cette défiance. Son projet a été exposé en Assemblée galactique :
--------------------
http://www.apocalypsis.org/assemblee/viewtopic?c_topic=3860&c_forum_page=1
--------------------
... Il sera noté que le projet ne prime pas sur la défiance. Ainsi, si vous désirez mettre un terme à l'Aryakisme, Le vote "Patogasse" s'impose.
Cas du vote blanc majoritaire :
... Nous parlons ici du "vote blanc", pas de l'abstention.
En cas de vote blanc majoritaire, Sachant que l'Aryakis à proposée de remettre la capitale sans condition : la capitale sera : Abandonnée.
