Modèle:CodeGalaxie

{{{1}}}


Utilisation 
Ce modèle renvoie un lien vers la galaxie, ou une sous-catégorie galactique, correspondant au code fourni.
Syntaxe 
{{CodeGalaxie|1|Type|Clé}}
Paramètres 
  • 1 = le numéro de la galaxie. Si inconnu, le paramètre sera affiché tel quel (facultatif, "Inconnue" par défaut).
  • Type = le type de lien à renvoyer : Lien, Principale, Organisation, Personnage, Intervention (facultatif, "Lien" par défaut).
  • Clé = clé de tri de la page quand Type=Intervention ; inutile pour les autres valeurs de Type.
Exemples 
* {{CodeGalaxie|0}} donne : Eveil
* {{CodeGalaxie|Inconnue}} donne : Inconnue
* {{CodeGalaxie}} donne : ?
