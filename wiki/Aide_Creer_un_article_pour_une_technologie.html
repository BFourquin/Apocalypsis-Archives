Aide:Créer un article pour une technologie

English
Ce guide est une aide pour les rédacteurs mais aussi un ensemble de pratiques et consignes à respecter pour conserver la cohérence du wiki. Le non-respect de ces pratiques est soumis à la modération des administrateurs comme décrit dans la charte. Pour signaler un article non-conforme, consultez Aide:Signaler un article.


Note que les sections "en bref" sont prévues pour les utilisateurs expérimentés et récapitulent les consignes. Toutefois, que que soit votre niveau, il est recommandé la première fois de lire le guide en entier.


Pour voir un exemple d'article technologique, consultez Techniques de piratage : amélioration 3


Rédiger l'article

En bref
  • Equivalent anglais : {{EN|Nom}}
  • Nom anglais obtenu via le jeu
  • Utilisez Modèle:Technologie
  • Valeurs possibles pour Type :
    • Attaque
    • Vitesse
    • Défense
    • Métaux
    • Energie
    • Diamants
    • Stabilité
    • Démographie
    • Bureaucratie
    • Productivité
    • Satisfaction
    • Ordre public
    • Civile
    • Sociale
    • Militaire
    • Secret

Avant toute chose, il faut créer un article vide. Pour cela, tapez dans la boîte de recherche le nom de la technologie pour laquelle vous voulez rédiger un article. La recherche ne donnera rien mais on vous proposera en haut un lien pour "créer cet article". Attention, il se peut que vous ayiez un problème de pages homonymes quand une technologie porte le même nom qu'un régime, une unité, etc... Pour cela, voir l'annexe "Homonymie".


Vous devez maintenant écrire le code de la page. Votre article va utiliser un modèle : celui-ci génèrera une mise en page (tableaux, etc) et ajoutera votre article à l'une des sous-catégories de Catégorie:Technologie. Pour cela, copiez/collez le code source de l'article de notre exemple. Voici à quoi il ressemble (les textes ont été abrégés) : 

{{EN|Renegade technics improvement 3}}
{{Technologie
|Type=Secret
|Profil=OR
|Palier=3
|Prérequis1=[[Hackers Drakaan]]
|Description=...
  • Sur la première ligne se trouve une référence à Modèle:EN, pour préciser le lien vers la page anglaise. Remplacez "Renegade technics improvement 3" par la traduction du nom de votre unité. Vous pouvez voir celle-ci en sélectionnant la langue de Shakespeare dans les options du jeu (onglet Identité).
  • Sur la même ligne on trouve ensuite une référence à Modèle:Technologie. Consultez la page de ce modèle pour accéder à sa documentation et comprendre quelles valeurs saisir pour les paramètres.
  • Notez les valeurs acceptables pour "Type" : celles-ci sont récapitulées dans l'encart de droite.
  • Quant au paramètre "Profil", celui-ci n'est nécessaire que pour les technologies secret-défense.
  • Pour les pré-requis, les doubles crochets dans notre exemple servent à faire un lien. En cas d'homonymie, voir l'annexe.
  • Pour le paramètre Description, nous vous conseillons de copier/coller celle du jeu à moins que vous n'ayiez envie de broder un peu de RP par-dessus cela.


Vous pouvez ajouter d'autres informations à la suite de ce modèle mais, en pratique, ça ne devrait pas être nécessaire. Votre article doit donc être terminé. Prévisualisez et vérifiez le tout, en comparant avec les informations du jeu. Quand c'est bon, sauvegardez. Merci de votre contribution !


Annexe : Homonymie

En bref
  • Utilisez Modèle:Page homonymie
  • Basez-vous sur République basique
  • Corvette sonar (technologie)
  • Corvette sonar (unité)

Supposons que vous vouliez faire un article sur la technologie Corvette sonar, nécessaire à l'unité Corvette sonar. Il y a homonymie et on utilisera trois pages :

  • Corvette sonar recensera toutes les pages homonymes de Corvette sonar (consultez République basique pour voir un exemple).
  • Corvette sonar (technologie) sera l'article sur la technologie nommée Corvette sonar.
  • Corvette sonar (unité) sera l'article sur l'infrastructure nommée Corvette sonar.


Nous allons maintenant voir comment faire la page Corvette sonar. Créez une page vide avec ce nom. Vous devrez utiliser le modèle Modèle:Page homonymie. Pour cela, collez le code suivant : 

{{EN|Sonar corvette}}{{Page homonymie}}
* [[Corvette sonar (unité)|Corvette sonar]], unité.
* [[Corvette sonar (technologie)|Corvette sonar]], technologie.


Quand vous aurez besoin de faire un lien vers la technologie Corvette Sonar, afin d'aviter de faire apparaître le suffixe (technologie) utilisez un lien comme ceci : [[Corvette sonar (technologie)|Corvette sonar]]. Ainsi, le lien pointera vers Corvette sonar (technologie) mais s'intitutlera Corvette sonar.
