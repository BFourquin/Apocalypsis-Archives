Modèle:CodeProfil

{{{1}}}


Utilisation 
Ce modèle renvoie un lien vers l'article du profil approprié.
Syntaxe 
{{CodeProfil|1}}
Paramètres 
  • 1 = le code du profil pour lequel on souhaite un lien (facultatif, "Tous" par défaut).
    • Pour l'Alliance, les codes acceptés sont : A, Alliance, alliance.
    • Pour la Fédération, les codes acceptés sont : F, Fédération, fédération.
    • Pour la Guilde, les codes acceptés sont : G, Guilde, guilde.
    • Pour l'Organisation Renégate : O, OR, or, O.R., R, Organisation, Renégat.
    • Autres : l'argument spécifié sera écrit tel quel.
Exemples 
* {{CodeProfil|F}} donne : Fédération
* {{CodeProfil|Aucun}} donne : Aucun
