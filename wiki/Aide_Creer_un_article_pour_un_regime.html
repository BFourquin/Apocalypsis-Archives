Aide:Créer un article pour un régime

English
Ce guide est une aide pour les rédacteurs mais aussi un ensemble de pratiques et consignes à respecter pour conserver la cohérence du wiki. Le non-respect de ces pratiques est soumis à la modération des administrateurs comme décrit dans la charte. Pour signaler un article non-conforme, consultez Aide:Signaler un article.


Note que les sections "en bref" sont prévues pour les utilisateurs expérimentés et récapitulent les consignes. Toutefois, que que soit votre niveau, il est recommandé la première fois de lire le guide en entier.


Au cours de ce guide, nous prendrons comme exemple les articles République basique et République basique (régime).


La page homonymie

En bref
  • Utilisez Modèle:Page homonymie
  • Basez-vous sur République basique
  • République basique (technologie)
  • République basique (régime)

En général, les régimes portent les mêmes noms que les technologies qui les rendent accessibles. Nous avons donc un problème d'homonymie. Pour le résoudre, nous aurons trois pages :

  • République basique recensera toutes les pages homonymes de République basique.
  • République basique (technologie) sera l'article sur la technologie nommée République basique.
  • République basique (régime) sera l'article sur le régime nommé République basique.


Nous allons commencer par créer la page République basique. Pour cela, faîtes une recherche sur République basique. Si la page n'existe pas (et bien sûr, puisque c'est notre exemple, elle existe), vous voyez apparaître, en haut des résultats de recherche, un lien pour "créer cet article". Cliquez et vous avez maintenant une page vide.


Il vous faut maintenant utiliser le modèle Modèle:Page homonymie. Voici le code de notre exemple, sur lequel vous baser : 

{{EN|Basic republic}}{{Page homonymie}}
* [[République basique (technologie)|République basique]], technologie.
* [[République basique (régime)|République basique]], régime.


L'article du régime proprement dit

En bref
  • Equivalent anglais :
    {{EN|Nom anglais}}
  • Nom anglais obtenu via le jeu (ajouter (government system))
  • Utilisez Modèle:Régime
  • Minuscules pour le texte du lien de la technologie
  • Majuscule au début pour NomAvecArticle

A nouveau il faut créer un article vide en procédant comme précédemment, via une recherche. Celui-ci utilisera le modèle Modèle:Régime. Voici le code de notre exemple : 

{{EN|Basic republic (government system)}}{{Régime
| Type=Démocratique
| NomAvecArticle=La république basique
| Technologie=[[République basique (technologie)|république basique]]
| Croissance = 20
| Productivité = 15
| Stabilité = 20
| Offensive = 15
| Défensive = 25
| Corruption = 40
| Bonheur = 50
| PolitiqueIncompatible1 = Imposition3 
| PolitiqueIncompatible2 = Education3 
| PolitiqueIncompatible3 = Police2 
}}


  • Sur la première ligne se trouve une référence à Modèle:EN, pour préciser le lien vers la page anglaise. Remplacez "Basic republic (government system)" par la traduction du nom de votre régime. Vous pouvez voir celle-ci en sélectionnant la langue de Shakespeare dans les options du jeu (onglet Identité).
  • Sur la même ligne on trouve ensuite une référence à Modèle:Régime. Consultez la page de ce modèle pour accéder à sa documentation et comprendre quelles valeurs saisir pour les paramètres.
  • Pour les technologies et politiques, notez que les doubles crochets dans notre exemple servent à faire un lien. Par ailleurs, notez la barre verticale ( | ) qui sépare le lien réel du texte qui apparaîtra.
  • Notez que le texte affiché pour la technologie est entièrement en minuscules. Veillez à respecter cette casse car la technologie est citée à la fin d'une phrase.
  • En revanche, pour le nom avec article, la majuscule est de mise au début : il commence une phrase.


Vous pouvez ajouter d'autres informations à la suite de ce modèle (informations historiques, récits RP, etc) mais, en pratique, ça ne devrait pas être nécessaire. Votre article doit donc être terminé. Prévisualisez et vérifiez le tout, en comparant avec les informations du jeu. Quand c'est bon, sauvegardez. Merci de votre contribution !
