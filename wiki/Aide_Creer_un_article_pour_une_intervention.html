Aide:Créer un article pour une intervention

English
Ce guide est une aide pour les rédacteurs mais aussi un ensemble de pratiques et consignes à respecter pour conserver la cohérence du wiki. Le non-respect de ces pratiques est soumis à la modération des administrateurs comme décrit dans la charte. Pour signaler un article non-conforme, consultez Aide:Signaler un article.


Note que les sections "en bref" sont prévues pour les utilisateurs expérimentés et récapitulent les consignes. Toutefois, que que soit votre niveau, il est recommandé la première fois de lire le guide en entier.


Au cours de ce guide, nous prendrons comme exemple l'article Intervention:Respects du Renouveau Renégat.

Nous parlons ici d"intervention", ce qui correspond en réalité à un sujet entier de l'Assemblée, d'une salle, etc... Nous ultiserons les termes "sujet" pour désigner des "messages".

Création et en-tête

En bref
  • Ajoutez le préfixe "Intervention:" (sans espaces) devant votre article
  • Utilisez :
    Modèle:Intervention

Avant toute chose, il faut créer un article vide. Pour cela, tapez dans la boîte de recherche le nom du sujet lequel vous voulez rédiger un article. La recherche ne donnera rien mais on vous proposera en haut un lien pour "créer cet article". Attention, il se peut que vous ayiez un problème de pages homonymes (portant le même nom) : pour un tel cas, référez-vous à l'annexe à la fin de l'article.


Vous devez maintenant écrire le code de la page. Votre article va utiliser un modèle : celui-ci génèrera une mise en page (tableaux, etc) et ajoutera votre article aux catégories appropriées. Pour cela, copiez/collez le code source de l'article de notre exemple. Voici à quoi il ressemble (les textes ont été abrégés) : 

{{Intervention
|Texte=...
|Galaxie=0
|Date=25/09/307}}


Sur la première ligne se trouve une référence à Modèle:Intervention. Consultez la page de ce modèle pour accéder à sa documentation et comprendre quelles valeurs saisir pour les paramètres.


Messages successifs

En bref
  • Ajoutez une ligne de séparation en commentaire dans votre code source
  • Utilisez Modèle:Intervention
  • Pour résumer certains messages, utilisez Modèle:Abrégé

A la suite de l'en-tête créé, vous allez maintenir placez la succession de messages, dans son intégralité ou non. Pour ce faire, nous allons utiliser le modèle Modèle:Citation. Si nous reprenons notre exemple, voici le code du premier message : 

<!--================================================-->
{{Citation|...
|Commandant=Renouveau Renégat
|Style=3
|ID=1885
|IDSujet=181}}


Quelques notes concernant ce code :

  • Sur la première ligne se trouve une ligne de commentaires, destinée à clarifier la lecture du code source. Ces commentaires n'apparaissent pas sur la page finale.
  • Sur la seconde ligne se trouve une référence à Modèle:Citation. Consultez la page de ce modèle pour accéder à sa documentation et comprendre quelles valeurs saisir pour les paramètres.
  • Le portrait n'apparaîtra que si l'article du commandant concerné a été correctement créé.


Abréger certains messages

Le but des articles sur les interventions n'est pas d'être exhaustif et de reproduire fidèlement l'Assemblée. Il s'agit à la place de reproduire la substance des échanges afin de faire comprendre l'histoire des événements. Dans cette optique, certains messages sont superflus car n'ayant pas été retenu par l'histoire. Le niveau d'importance que chacun conservera est laissé à son propre jugement mais nous vous prions de bien y réfléchir. Nous nous bornerons ici à expliquer comment abréger certains messages. Par ailleurs, voyez notre exemple pour y observer un tel raccourci.


Dans votre code, insérez par exemple le code suivant : 

{{Abrégé|S'en suit une empoignade entre divers commandants, des protestations, des menaces. Rien d'inhabituel, donc, passons...}}


Annexe : Homonymie

En bref
  • Utilisez Modèle:Page homonymie
  • Basez-vous sur République basique
  • Guerre ! (Eveil, par Katradhan)
  • Guerre ! (Espoir, par Trucmuche)

Supposons que vous vouliez faire un article sur un sujet nommé "Guerre !" et qu'une autre intervention existe déjà. Il y a homonymie et on utilisera trois pages :

  • Guerre ! recensera toutes les pages homonymes de Corvette sonar (consultez République basique pour voir un exemple).
  • Guerre ! (Eveil, par Katradhan) sera l'article sur l'intervention de Katradhan, dans la galaxie Eveil.
  • Guerre ! (Espoir, par Trucmuche) sera l'article sur l'intervention de Trucmuche, dans la galaxie Espoir.


Nous allons maintenant voir comment faire la page Guerre !. Créez une page vide avec ce nom. Vous devrez utiliser le modèle Modèle:Page homonymie. Pour cela, collez le code suivant : 

{{Page homonymie}}
* [[Guerre ! (Eveil, par Katradhan)]].
* [[Guerre ! (Espoir, par Trucmuche)]].
