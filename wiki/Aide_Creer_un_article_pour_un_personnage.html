Aide:Créer un article pour un personnage

English
Ce guide est une aide pour les rédacteurs mais aussi un ensemble de pratiques et consignes à respecter pour conserver la cohérence du wiki. Le non-respect de ces pratiques est soumis à la modération des administrateurs comme décrit dans la charte. Pour signaler un article non-conforme, consultez Aide:Signaler un article.


Note que les sections "en bref" sont prévues pour les utilisateurs expérimentés et récapitulent les consignes. Toutefois, que que soit votre niveau, il est recommandé la première fois de lire le guide en entier.


Au cours de ce guide, nous prendrons comme exemple l'article Commandant:Katradhan.

Note : Presque tous les champs du modèle sont optionnels, seule galaxie est obligatoire. Dans ce cas, vous obtiendrez une mise en page minimaliste, comme affiché sur la page Modèle:Personnage.


L'image

En bref
  • Nom de l'image = nom du commandant + ".jpg"
  • Description : {{Avatar}}

Avant toute chose, il vous faut importer l'image de l'unité.

  • Enregistrez-la sur votre disque dur.
  • Si nécessaire, convertissez-la au format jpeg.
  • Puis, pour l'enregistrer sur le serveur, cliquez sur "Importer une image ou un son" (boîte à outils, dans la marge gauche du wiki).


Dans le champ "Nom sous lequel le fichier sera enregistré", tapez par exemple "Katradhan.jpg".

  • Attention : le nom de l'image doit être exactement le même, au caractère près, que celui de votre commandant. Plus, à la fin, l'extension ".jpg".
  • N'ajoutez pas le préfixe "Image:", il le sera automatiquement.


Dans le champ "Description", tapez ceci : {{Avatar}}. Ceci détaillera les droits associés aux images tirées du jeu et catégorisera cette image comme "Avatar".

  • Attention : les droits des avatars sont incertains : vous êtes légalement responsable de l'importation de cette image sur le wiki, même si ce n'est pas vous qui avez placé cet avatar dans le jeu.
  • Si vous connaissez la source de l'image, merci de la préciser en rajoutant au début de la description : '''Source : ''' Source de l'image


Si vous rencontrez une erreur système en validant, c'est que l'image est trop grande (environ deux millions de pixels maximum).

Si vous voulez en savoir plus sur l'importation des images, consultez Aide:Importer une image.


L'article

En bref
  • Nom de l'article = "Commandant:" + nom du commandant
  • Utilisez Modèle:Personnage

Avant toute chose, il faut créer un article vide. Pour cela, tapez dans la boîte de recherche le nom de l'article à créer. Attention : l'article doit commencer par le préfixe "Commandant:", sans espaces après les deux points. Par exemple, pour Katradhan, ce sera "Commandant:Katradhan". Si cet article n'existe pas, la recherche ne donnera rien mais on vous proposera en haut un lien pour "créer cet article".


Vous devez maintenant écrire le code de la page. Votre article va utiliser un modèle : celui-ci génèrera une mise en page (tableaux, etc) et ajoutera votre article à la catégorie "Commandant". Pour cela, copiez/collez le code source de l'article de notre exemple. Voici à quoi il ressemble (les textes ont été abrégés) : 

{{Personnage
|Sexe=Homme
|Profil=OR
|Galaxie=0
|Coalition1=[[Coalition:Renouveau Renégat|Renouveau Renégat]] (fondateur)}}


  • Sur la première ligne se trouve une référence à Modèle:Personnage. Consultez la page de ce modèle pour accéder à sa documentation et comprendre quelles valeurs saisir pour les paramètres.
  • Pour les principales coalitions auxquelles ce commandant a appartenu les technologies, notez que les doubles crochets dans notre exemple servent à faire un lien. En premier lieu se trouve le nom de l'article (Coalition:Renouveau Renégat) et en second se trouve le texte qui apparaîtra dans le lien (Renouveau Renégat). Enfin, nous avons rajouté la mention "fondateur" pour indiquer que Katradhan était le fondateur du Renouveau Renégat.


Vous pouvez ensuite laisser libre cours à votre imagination pour ajouter tout ce que vous voudrez à la suite de ce modèle. Votre article est maintenant terminé : prévisualisez, vérifiez le tout, et traquez d'éventuelles fautes de français. Quand c'est bon, sauvegardez. Merci de votre contribution !
