Utilisation 
Ce modèle fournit une base pour les articles portant sur des personnages.


Syntaxe 
{{Personnage|Age|Sexe|Civilisation|Gouvernement|Coalition1|...


Paramètres importés du profil apparaissant dans le jeu 
  • Galaxie = la galaxie d'origine de ce personnage. Voir Modèle:CodeGalaxie pour plus de détails.
  • Age = l'âge de ce personnage (facultatif, masqué par défaut).
  • Sexe = le sexe de ce personnage (facultatif, masqué par défaut).
  • Profil = le profil de ce personnage (facultatif, masqué par défaut). Voir Modèle:CodeProfil pour plus de détails.
  • Civilisation = le nom de la civilisation de ce personnage (facultatif, masqué par défaut).
  • Gouvernement = le nom du gouvernement de cette civilisation (facultatif, masqué par défaut).
  • Coalition1 à 5 = coalitions auxquelles ce personnage a appartenu (facultatif, masqué par défaut).
