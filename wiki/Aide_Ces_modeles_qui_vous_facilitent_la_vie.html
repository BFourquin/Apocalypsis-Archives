Modèle:En travaux

Ce modèle permet de signaler qu'une page est inachevée et que vous continuez à travailler dessus.

Cette section n'est qu'une ébauche.


Pour l'utiliser, copiez le code suivant dans votre page : 

{{En travaux}} OU {{En travaux|Cette section n'est qu'une ébauche.}}



Modèle:Citation

Ce modèle vous permet d'intégrer facilement ét élégamment des citations d'interventions dans vos articles. Il offre l'avantage de fournir au lecteur un lien vers la page du commandant et l'intervention complète.


Version discrète (style=1)

 Si vous n'obtempérez pas, vous n'aurez plus l'occasion de vous présenter ici, et serez le premier exclu de ce Gouvernement. Vous pourrez retourner à votre secteur lointain, vous occuper de vos petites affaires...
   
   



Pour utiliser cette version, placez le code suivant dans votre page (le dernier paramètre est facultatif et le code 2678 est obtenu en plaçant la souris au-dessus des grands guillemets dans l'intervention originale) : 

{{Citation|...|Style=1|Commandant=Katradhan|Intervention=Intervention:Respects du Renouveau Renégat#2678}}


Version simple (style=2)

 Cdt. Aristippe,

Le Renouveau Renégat s'abaisse à vous répondre, et vous le provoquez en retour?

Dois-je vous rappeler qui héberge la Capitale de cette Assemblée Galactique? Dois-je vous rappeler à qui vous devez la stabilité actuelle des marchés de Contrebande? Dois-je vous rappeler que j'ai le pouvoir de vous exclure immédiatement de cette Assemblée?

J'attends de vous des excuses immédiates et publiques.

Si vous n'obtempérez pas, vous n'aurez plus l'occasion de vous présenter ici, et serez le premier exclu de ce Gouvernement. Vous pourrez retourner à votre secteur lointain, vous occuper de vos petites affaires...

   
   



Pour utiliser cette version, placez le code suivant dans votre page (le dernier paramètre est facultatif et le code 2678 est obtenu en plaçant la souris au-dessus des grands guillemets dans l'intervention originale) : 

{{Citation|...|Style=2|Commandant=Katradhan|Intervention=Intervention:Respects du Renouveau Renégat#2678}}

Modèle:Bandeau

Ce modèle sert à mettre en évidence une information particulièrement importante.

Cette information est importante !


Pour l'utiliser, placez le code suivant dans votre page : 

{{Bandeau|Cette information est importante !}}



Modèle:En bref

Ce modèle sert à récapituler, donner une astuce, etc... Il se détache du texte, attire l'oeil sans rompre le flux du texte, mais ne fournit pas une information essentielle. En voici un exemple (à droite) et le code nécessaire pour l'utiliser.


En bref
Utile, n'est-ce pas ?

Modèle:TableauElegant (et autres)

Pour créer des tableaux élégants, plusieurs modèles sont disponibles pour vous aider. Ces modèles sont :

  • Modèle:TableauElegant
  • Modèle:LigneTitre
  • Modèle:LigneClaire
  • Modèle:LigneSombre
  • Modèle:LigneClaire2
  • Modèle:LigneSombre2


Tableaux à une colonne

Voici un exemple (à gauche) et le code à ajouter à votre page pour l'obtenir.


Ceci est un titre
Première ligne
Seconde ligne
Troisième ligne
Quatrième ligne
Cinquième ligne
Sixième ligne 
{{TableauElegant|align=left|valign=top|margeSup=0|margeInf=20|1=
{{LigneTitre|Ceci est un titre}}
{{LigneClaire|Première ligne}}
{{LigneSombre|Seconde ligne}}
{{ContenuListe
|Troisième ligne
|Quatrième ligne
|Cinquième ligne
|Sixième ligne}}}}



Tableaux à deux colonnes

Voici un exemple (à gauche) et le code à ajouter à votre page pour l'obtenir. Notez que les modèles Modèle:LigneClaire et Modèle:LigneSombre sont remplacés par Modèle:LigneClaire2 et Modèle:LigneSombre2. En revanche, Modèle:LigneTitre et Modèle:ContenuListe ne peuvent être utilisés que pour des lignes occupant les deux colonnes, via l'option "colspan=2".


Ceci est un titre
A B
C D
Troisième ligne
Quatrième ligne
Cinquième ligne
Sixième ligne 
{{TableauElegant|align=left|valign=top|margeSup=0|margeInf=20|1=
{{LigneTitre|Ceci est un titre|Options=colspan=2}}
{{LigneClaire2|A|B|Options=align="center"}}
{{LigneSombre2|C|D|Options=align="center"}}
{{ContenuListe
|Troisième ligne
|Quatrième ligne
|Cinquième ligne
|Sixième ligne
|Options=colspan=2 align="center"}}}}
