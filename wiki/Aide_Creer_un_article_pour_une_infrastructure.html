Aide:Créer un article pour une infrastructure

English
Ce guide est une aide pour les rédacteurs mais aussi un ensemble de pratiques et consignes à respecter pour conserver la cohérence du wiki. Le non-respect de ces pratiques est soumis à la modération des administrateurs comme décrit dans la charte. Pour signaler un article non-conforme, consultez Aide:Signaler un article.


Note que les sections "en bref" sont prévues pour les utilisateurs expérimentés et récapitulent les consignes. Toutefois, que que soit votre niveau, il est recommandé la première fois de lire le guide en entier.


Au cours de ce guide, nous prendrons comme exemple l'article Zone de colonisation.


L'image

En bref
  • Divisez la taille de l'image par deux avant de l'importer.
  • Format du nom :
    "Zone de colonisation.jpg"
  • Description :
    {{Copyright Apocalypsis}}

Avant toute chose, il vous faut importer l'image de l'infrastructure : dans le jeu elle apparaît en arrière-plan de la fenêtre de construction.

  • Enregistrez-la sur votre disque dur.
  • L'image que vous avez ainsi sauvegardée est trop grande, aussi divisez sa taille par deux. Sinon vous rencontrerez une erreur système.


Puis, pour l'enregistrer sur le serveur, cliquez sur "Importer une image ou un son" (boîte à outils, dans la marge gauche du wiki).

  • Dans le champ "Nom sous lequel le fichier sera enregistré", tapez par exemple "Zone de colonisation.jpg".
    • Utilisez la même casse (une seule majuscule) et utilisez des espaces plutôt que des caractères "_" (underscore).
    • N'ajoutez pas le préfixe "Image:", il le sera automatiquement.
    • N'oubliez pas l'extension (.jpg, .png, ...).
  • Dans le champ "Description", tapez ceci : {{Copyright Apocalypsis}}. Ceci détaillera les droits associés aux images tirées du jeu et catégorisera cette image comme "Image du jeu".


Si vous voulez en savoir plus sur l'importation des images, consultez Aide:Importer une image.


L'article

En bref
  • Equivalent anglais :
    {{EN|Nom anglais}}
  • Nom anglais obtenu via le jeu
  • Utilisez Modèle:Infrastructure
  • Description : premier paragraphe automatiquement en italique
  • Copiez/collez la description
  • Rédigez une observation si nécessaire

Avant toute chose, il faut créer un article vide. Pour cela, tapez dans la boîte de recherche le nom de l'infrastructure pour laquelle vous voulez rédiger un article. La recherche ne donnera rien mais on vous proposera en haut un lien pour "créer cet article". Attention, il se peut que vous ayiez un problème de pages homonymes si la technologie et l'infrastructure portent le même nom. Pour un tel cas, référez-vous à l'annexe à la fin de l'article.


Vous devez maintenant écrire le code de la page. Votre article va utiliser un modèle : celui-ci génèrera une mise en page (tableaux, etc) et ajoutera votre article à la catégorie "Infrastructure". Pour cela, copiez/collez le code source de l'article de notre exemple. Voici à quoi il ressemble (les textes ont été abrégés) : 

{{EN|Colonisation zone}}{{Infrastructure
| Image=Zone de colonisation.jpg
| Maximum=10
| Technologie1=[[Urbanisme avancé]]
| Leems=200000
| Métaux=100000
| Diamants=20
| Energie=15000
| Description=(...)
| Observations=(...)}}


  • Sur la première ligne se trouve une référence à Modèle:EN, pour préciser le lien vers la page anglaise. Remplacez "Colonisation Zone" par la traduction du nom de votre infrastructure. Vous pouvez voir celle-ci en sélectionnant la langue de Shakespeare dans les options du jeu (onglet Identité).
  • Sur la même ligne on trouve ensuite une référence à Modèle:Infrastructure. Consultez la page de ce modèle pour accéder à sa documentation et comprendre quelles valeurs saisir pour les paramètres.
  • Pour les technologies, notez que les doubles crochets dans notre exemple servent à faire un lien. En cas d'homonymie, voir l'annexe.
  • Pour le paramètre Description, nous vous conseillons de copier/coller celle du jeu (libre à vous, peut-être voulez-vous commettre un peu de RP). Le premier paragraphe sera automatiquement mis en italique. Pour mettre les paragraphes suivants en italique également, entourez-les de deux signes apostrophes (attention, pas des guillemets) : ''exemple''.
  • Viennent ensuite les éventuelles observations, c'est à dire des explications supplémentaires sur le fonctionnement de ce bâtiment. Est-ce nécessaire ? Si oui, alors plutôt que de copier/coller depuis le jeu, nous vous conseillons de rédiger une explication claire, concise mais complète.


Vous pouvez ajouter d'autres informations à la suite de ce modèle mais, en pratique (à moins que vous ne souhaitiez ajouter un récit RP par exemple), ça ne devrait pas être nécessaire. Votre article doit donc être terminé. Prévisualisez et vérifiez le tout, en comparant avec les informations du jeu. Quand c'est bon, sauvegardez. Merci de votre contribution !


Annexe : Homonymie

En bref
  • Utilisez Modèle:Page homonymie
  • Basez-vous sur République basique
  • Bidule (technologie)
  • Bidule (infrastructure)

Supposons que vous vouliez faire un article sur une infrastructure Bidule, nécesitant la technologie Bidule. Il y a homonymie et on utilisera trois pages :

  • Bidule recensera toutes les pages homonymes de Bidule (consultez République basique pour voir un exemple).
  • Bidule (technologie) sera l'article sur la technologie nommée Bidule.
  • Bidule (infrastructure) sera l'article sur l'infrastructure nommée Bidule.


Nous allons maintenant voir comment faire la page Bidule. Créez une page vide avec ce nom. Vous devrez utiliser le modèle Modèle:Page homonymie. Pour cela, collez le code suivant : 

{{EN|Stuff}}{{Page homonymie}}
* [[Bidule (infrastructure)|Bidule]], infrastructure.
* [[Bidule (technologie)|Bidule]], technologie.


Dans la page de l'infrastructure, quand vous préciserez les technologies requises, utilisez un lien comme ceci : [[Bidule (technologie)|Bidule]]. Ainsi, le lien pointera vers Bidule (technologie) mais s'intitutlera Bidule.
