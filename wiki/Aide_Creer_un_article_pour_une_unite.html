Aide:Créer un article pour une unité

English
Ce guide est une aide pour les rédacteurs mais aussi un ensemble de pratiques et consignes à respecter pour conserver la cohérence du wiki. Le non-respect de ces pratiques est soumis à la modération des administrateurs comme décrit dans la charte. Pour signaler un article non-conforme, consultez Aide:Signaler un article.


Note que les sections "en bref" sont prévues pour les utilisateurs expérimentés et récapitulent les consignes. Toutefois, que que soit votre niveau, il est recommandé la première fois de lire le guide en entier.


Au cours de ce guide, nous prendrons comme exemple l'article Frégate corsaire.


L'image

En bref
  • Divisez la taille de l'image par deux avant de l'importer.
  • Format du nom :
    "Frégate corsaire.jpg"
  • Description :
    {{Copyright Apocalypsis}}

Avant toute chose, il vous faut importer l'image de l'unité : dans le jeu elle apparaît en arrière-plan de la fenêtre de construction.

  • Enregistrez-la sur votre disque dur.
  • L'image que vous avez ainsi sauvegardée est trop grande, aussi divisez sa taille par deux. Sinon vous rencontrerez une erreur système.


Puis, pour l'enregistrer sur le serveur, cliquez sur "Importer une image ou un son" (boîte à outils, dans la marge gauche du wiki).

  • Dans le champ "Nom sous lequel le fichier sera enregistré", tapez par exemple "Frégate corsaire.jpg".
    • Utilisez la même casse (une seule majuscule) et utilisez des espaces plutôt que des caractères "_" (underscore).
    • N'ajoutez pas le préfixe "Image:", il le sera automatiquement.
    • N'oubliez pas l'extension (.jpg, .png, ...).
  • Dans le champ "Description", tapez ceci : {{Copyright Apocalypsis}}. Ceci détaillera les droits associés aux images tirées du jeu et catégorisera cette image comme "Image du jeu".


Si vous voulez en savoir plus sur l'importation des images, consultez Aide:Importer une image.


L'article

En bref
  • Equivalent anglais :
    {{EN|Nom anglais}}
  • Nom anglais obtenu via le jeu
  • Utilisez Modèle:Unité
  • Description : premier paragraphe automatiquement en italique
  • Copiez/collez la description
  • Rédigez une observation si nécessaire

Avant toute chose, il faut créer un article vide. Pour cela, tapez dans la boîte de recherche le nom de l'unité pour laquelle vous voulez rédiger un article. La recherche ne donnera rien mais on vous proposera en haut un lien pour "créer cet article". Attention, il se peut que vous ayiez un problème de pages homonymes si la technologie et l'infrastructure portent le même nom. Pour un tel cas, référez-vous à l'annexe à la fin de l'article.


Vous devez maintenant écrire le code de la page. Votre article va utiliser un modèle : celui-ci génèrera une mise en page (tableaux, etc) et ajoutera votre article à la catégorie "Unité". Pour cela, copiez/collez le code source de l'article de notre exemple. Voici à quoi il ressemble (les textes ont été abrégés) : 

{{EN|Privateer frigate}}{{Unité
| Image=Frégate corsaire.jpg
| Infrastructure1=[[Plateforme spécialisée]]
| TypeUnité=Militaire
| Profil=OR
| Attaque=2
| Défense=2
| Vitesse=4
| Leems=4200
| Métaux=5100
| Diamants=2
| Energie=2600
| Habitants=50
| EntretienLeems=20
| EntretienEnergie=20
| Ordre1=[[Pillage planétaire]]
| Ordre2=[[Pillage commercial]]
| Ordre3=[[Invasion]]
| Description=(...)
| Observations=(...)}}


  • Sur la première ligne se trouve une référence à Modèle:EN, pour préciser le lien vers la page anglaise. Remplacez "Privateer frigate" par la traduction du nom de votre unité. Vous pouvez voir celle-ci en sélectionnant la langue de Shakespeare dans les options du jeu (onglet Identité).
  • Sur la même ligne on trouve ensuite une référence à Modèle:Unité. Consultez la page de ce modèle pour accéder à sa documentation et comprendre quelles valeurs saisir pour les paramètres.
  • Pour les technologies, notez que les doubles crochets dans notre exemple servent à faire un lien. En cas d'homonymie, voir l'annexe.
  • Pour le paramètre Description, nous vous conseillons de copier/coller celle du jeu, à moins que vous ne vouliez broder un peu de RP. Quoi qu'il en soit, le premier paragraphe sera automatiquement mis en italique. Pour mettre les paragraphes suivants en italique également, entourez-les de deux signes apostrophes (attention, pas des guillemets) : ''exemple''.
  • Viennent ensuite les éventuelles observations, c'est à dire des explications supplémentaires sur le fonctionnement de cette unité. Est-ce nécessaire ? Ces informations ne sont-elles pas déjà disponibles ailleurs ? Si oui, alors plutôt que de copier/coller depuis le jeu, nous vous conseillons de rédiger une explication claire, concise mais complète.


Vous pouvez ajouter d'autres informations à la suite de ce modèle mais, en pratique, ça ne devrait pas être nécessaire (à moins bien sûr que vous ne souhaitiez ajouer un petit récit RP, cela peut être bienvenu). Votre article doit donc être terminé. Prévisualisez et vérifiez le tout, en comparant avec les informations du jeu. Quand c'est bon, sauvegardez. Merci de votre contribution !

Annexe : Homonymie

En bref
  • Utilisez Modèle:Page homonymie
  • Basez-vous sur République basique
  • Corvette sonar (technologie)
  • Corvette sonar (unité)

Supposons que vous vouliez faire un article sur l'unité Corvette sonar, nécesitant la technologie Corvette sonar. Il y a homonymie et on utilisera trois pages :

  • Corvette sonar recensera toutes les pages homonymes de Corvette sonar (consultez République basique pour voir un exemple).
  • Corvette sonar (technologie) sera l'article sur la technologie nommée Corvette sonar.
  • Corvette sonar (unité) sera l'article sur l'infrastructure nommée Corvette sonar.


Nous allons maintenant voir comment faire la page Corvette sonar. Créez une page vide avec ce nom. Vous devrez utiliser le modèle Modèle:Page homonymie. Pour cela, collez le code suivant : 

{{EN|Sonar corvette}}{{Page homonymie}}
* [[Corvette sonar (unité)|Corvette sonar]], unité.
* [[Corvette sonar (technologie)|Corvette sonar]], technologie.


Dans la page de l'unité, quand vous préciserez les technologies requises, utilisez un lien comme ceci : [[Corvette sonar (technologie)|Corvette sonar]]. Ainsi, le lien pointera vers Corvette sonar (technologie) mais s'intitutlera Corvette sonar.
