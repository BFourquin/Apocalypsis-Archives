Utilisation 
Ce modèle forme la base des articles portant sur des régimes.
Syntaxe 
{{Régime|NomAvecArticle|Type|Technologie|Croissance|Productivité|Stabilité|Offensive|Défensive|Corruption|Bonheur
|PolitiqueIncompatible1|...}}
Paramètres 
  • NomAvecArticle = nom du régime précédé de son article (le, la) et commençant par une majuscule.
  • Type = famille du régime telles que définies dans Types de gouvernement (facultatif, aucune famille par défaut : despotisme). Valeurs possibles : Militaire, militaire, Démocratique, démocratique, Féodal, féodal, Religieux, religieux, Marxiste, marxiste.
  • Technologie = technologie requise (faculatif).
  • Croissance = bonus de base pour la croissance démographique.
  • Productivité = bonus de base pour la productivité économique.
  • Stabilité = bonus de base pour la stabilité économique.
  • Offensive = bonus de base pour la capacité offensive.
  • Défensive = bonus de base pour la capacité défensive.
  • Corruption = bonus de base pour le crime et la corruption.
  • Bonheur = bonus de base pour le facteur de bonheur.
  • PolitiqueIncompatible1 à 9 = politiques incompatibles avec ce régime (facultatif). Les valeurs possibles sont les mêmes que pour Modèle:CodePolitique.
