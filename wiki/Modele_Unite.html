Utilisation 
Ce modèle expose les informations relatives à une unité.
Syntaxe 
{{Unité
|Description|Observations|Image|TypeUnité|Profil|Attaque|Défense|Vitesse|RésistanceIonique|Frêt|Leems|Métaux|Diamants|Energie|Apotium|Habitants|EntretienLeems|EntretienEnergie
|Ordre1|...|Technologie1|...|Infrastructure1|...}}
Paramètres 
  • Description = la description de cette infrastructure, telle que donnée dans le jeu.
  • Observations = observations complémentaires sur le fonctionnement de cette infrastructure.
  • Image = le nom de l'image de l'infrastucture, sans l'espace de noms "Image" (facultatif, "Logo Apocalypsis.png" par défaut).
  • TypeUnité = désigne le type d'unité. Valeurs acceptées : Civil, civil, Militaire, militaire, Spécial, spécial.
  • Profil = désigne le profil auquel appartient cette unité : Alliance (1), Fédération (2), Guilde (3), OR (4) (facultatif, "Tous" par défaut).
  • Maximum = le nombre maximal d'instrasturtcures de ce type par planète (facultatif, champ masqué par défaut).
  • Attaque = le facteur d'attaque de l'unité (facultatif, 0 par défaut).
  • Défense = le facteur de défense de l'unité (facultatif, 0 par défaut).
  • Vitesse = le facteur de vitesse de l'unité (facultatif, 0 par défaut).
  • Résistance Ionique = le facteur de résistance ionique de l'unité (facultatif, 0 par défaut).
  • Frêt = le capacité de frêt de l'unité (facultatif, masqué par défaut).
  • Leems = coût de la construction en leems (facultatif, 0 par défaut).
  • Métaux = coût de la construction en métaux (facultatif, 0 par défaut).
  • Diamants = coût de la construction en diamants (facultatif, 0 par défaut).
  • Energie = coût de la construction en énergie (facultatif, 0 par défaut).
  • Apotium = coût de la construction en apotium (facultatif, champ masqué par défaut ou si le paramètre est nul).
  • Habitants = coût de la construction en habitants (facultatif, 0 par défaut).
  • EntretienLeems = frais d'entretien en leems (facultatif, "?" par défaut).
  • EntretienEnergie = frais d'entretien en énergie (facultatif, "?" par défaut).
  • Ordre1 à 5 = ordres associés à l'infrastructure, déplacements exceptés (facultatif).
  • Technologie1 à 10 = technologies requises (facultatif).
  • Infrastructure1 à 4 = infrastructures requises en-dehors du chantier spatial (facultatif).
